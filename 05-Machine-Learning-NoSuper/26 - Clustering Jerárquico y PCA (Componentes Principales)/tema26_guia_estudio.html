Teoría 1 de 2

#Clustering aglomerativo y Ward

ideas_clave.py

aglomerativo # bottom-up
Cada cliente empieza solo; se une el par más parecido hasta quedar un solo grupo.


distancia_euclidiana # d = raíz(suma (xi - yi)^2)
Línea recta entre dos clientes en el espacio de 9 variables.


ward # criterio de enlace
Une los grupos cuya fusión aumenta menos la varianza interna: grupos compactos.

leer_dendrograma.md

eje X clientes (las hojas)


eje Y altura de fusión: más alto = grupos más distintos


corte una línea horizontal cruza tantas ramas como clústeres quieras


regla busca un salto grande entre una fusión y la siguiente

Teoría 2 de 2

#PCA: componentes y varianza

conceptos_pca.py

componentes # PC1, PC2, ...
Combinaciones lineales de las variables, no correlacionadas y ordenadas por varianza.


varianza_explicada # % por componente
Cuánta información conserva cada eje. Con 2 ejes no se conserva toda.


cargas # loadings
Peso de cada variable en un componente: sirven para interpretar el eje.

tres_ideas.md

idea 1 el clustering usa las 9 variables; el PCA solo sirve para dibujar


idea 2 en 2D los grupos pueden verse encimados aunque en 9D estén separados


idea 3 el signo de un eje es arbitrario; interpreta qué variables se agrupan

#Glosario

Aglomerativo
cada cliente empieza solo y se fusionan los más parecidos
Distancia euclidiana
línea recta entre dos puntos
Ward
fusión con menor aumento de varianza interna
Dendrograma
árbol de fusiones; la altura es la distancia
Estandarización
media 0 y desviación 1 por variable
Silueta
de −1 a 1: qué tan bien encaja un punto en su clúster
ARI
1 = particiones idénticas; 0 = azar
Componente principal
combinación lineal, no correlacionada, ordenada por varianza
Varianza explicada
porcentaje de información de cada componente
Cargas
peso de cada variable en un componente

#Repaso y ejercicios

¿Por qué estandarizar?

Las variables de mayor escala dominarían la distancia; sin escalar el ARI es 0.14.

¿k = 4 es el óptimo?

No: el mayor salto está en k = 3 y la silueta es plana. Es una decisión.

¿Cuánta información muestra el 2D?

36.1 % de la varianza: una vista parcial.

¿Qué significa una silueta de 0.08?

El cliente está en la frontera entre dos grupos; su recomendación es menos fiable.

¿Cómo se asigna un cliente nuevo?

Se escala con el scaler ajustado y se toma el centroide más cercano.
